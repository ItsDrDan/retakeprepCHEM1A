# Exam Retake Prep: CHEM 1A (private link for Dr. Dan's students)

Practice for CHEM 1A Exams 1, 2 and 3, with hints, step-by-step solutions and feedback on common mistakes.

- **Mock Exam**: a full 100-point practice exam. Questions regenerate with new numbers and compounds.
- **Train**: one question at a time, by topic.
- **Weak Spots**: what the student keeps missing, with a button to practice it.

Not listed on the study hub on purpose (`noindex`). Share the link through Canvas.

No real exams are stored in this repository. Do not add them.

Game design and chemistry by ItsDrDan. AI (Claude by Anthropic) helped write the code.
